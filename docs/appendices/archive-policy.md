# Source archive policy

> Status: ACTIVE technical appendix. Patch production remains governed by the separate normative `regles-generales-production.md` supplied by the GPT Web session.

The distributable project snapshot contains source code, build configuration, packaging, maintained documentation and regression tests. Public reference data is limited to small synthetic fixtures that can be reviewed in a normal diff.

The snapshot excludes:

- build outputs and CMake caches;
- `.git` and IDE caches;
- runtime databases, settings, thumbnails, temporary files and logs;
- HAR captures, `session.json`, tokens, cookies, signed URLs and TLS private material;
- local real-world PWSZ/Photon samples without redistribution rights;
- the external governance file `regles-generales-production.md`;
- the external offline dependency bundle `accloud-build-deps.zip`.

`acm.zip` is provided manually by the user and is not generated by a repository script. The active archive is identified by its exact byte size and extracted into a new working directory. An older extraction or patch chain must not be reused as a newer source of truth.

The documentation contract validates maintained Markdown, public synthetic reference data and key archive-policy invariants, but it does not create or replace `acm.zip`.
