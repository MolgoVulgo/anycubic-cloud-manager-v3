# Runtime environment variables

> Status: ACTIVE technical appendix. Environment overrides are diagnostic and deployment controls, not a replacement for the observed Anycubic contracts.

Boolean values accept the forms handled by the owning code (`1/0`, `true/false`, `yes/no`, `on/off` where supported).

## Local paths

| Variable | Purpose |
| --- | --- |
| `ACCLOUD_PATHS_INI` | Override the INI file that resolves application paths. |
| `ACCLOUD_SESSION_PATH` | Override `session.json`. This file remains secret. |
| `ACCLOUD_DB_PATH` | Override the SQLite cache path. |
| `ACCLOUD_THUMBNAIL_DIR` | Override the thumbnail cache directory. |
| `ACCLOUD_LOG_DIR` | Override the structured log directory. |
| `ACCLOUD_MQTT_OPENSSL_CONF_PATH` | Override the generated OpenSSL compatibility configuration path. |

## MQTT identity and credentials

| Variable | Purpose and constraint |
| --- | --- |
| `ACCLOUD_MQTT_AUTH_MODE` | Preferred credential profile (`slicer`, `android` or supported resolver value). Production runtime remains `slicer`. |
| `ACCLOUD_MQTT_ANDROID_COMPAT` | Enables the internal Android compatibility candidate. Diagnostic only; it must not replace the validated slicer profile. |
| `ACCLOUD_MQTT_AUTH_TOKEN` | Overrides the MQTT auth token loaded from the session. Secret. |
| `ACCLOUD_MQTT_EMAIL` | Overrides the account email used by the credential builder. Personal data. |
| `ACCLOUD_MQTT_USER_ID` | Overrides the account identifier. Personal/pseudonymous data. |
| `ACCLOUD_MQTT_MODE_AUTH` | Overrides session metadata `mode_auth`; retained for compatibility with imported sessions. |

## MQTT TLS

| Variable | Purpose and constraint |
| --- | --- |
| `ACCLOUD_MQTT_TLS_CA_PATH` | CA material used by the slicer credential/TLS path. |
| `ACCLOUD_MQTT_TLS_CLIENT_CERT_PATH` | Client certificate for mTLS. |
| `ACCLOUD_MQTT_TLS_CLIENT_KEY_PATH` | Private client key for mTLS. Secret; never package or log it. |
| `ACCLOUD_MQTT_TLS_ALLOW_INSECURE` | Defaults to `true` in the validated broker compatibility path and permits `VerifyNone`. This is frozen MQTT compatibility, not a global SSL policy. |
| `ACCLOUD_MQTT_TLS_DEV_FALLBACK` | Explicit lookup under `<repo>/resources/mqtt/tls` for development material. The generic runtime defaults to disabled; the repository-local `start.sh` launcher explicitly defaults it to `1`, preserves caller-provided values, and never overrides explicit TLS paths. |

## MQTT observation and UI diagnostics

| Variable | Purpose |
| --- | --- |
| `ACCLOUD_MQTT_EXTENDED_TOPICS` | Adds controlled observed topic variants. |
| `ACCLOUD_MQTT_CAPTURE_PATH` | Writes a redacted MQTT observation capture to an explicit path. Do not use with public identifiers. |
| `ACCLOUD_UI_PERF_TRACE` | Enables UI performance traces. |

## Cloud header/signature overrides

These values reproduce observed client headers and signing profiles. Changing them can invalidate cloud calls. Never print secret values.

| Current variable | Compatibility alias | Purpose |
| --- | --- | --- |
| `ACCLOUD_PUBLIC_APP_ID` | `ACCLOUD_WORKBENCH_APP_ID` | Public/Workbench application identifier. |
| `ACCLOUD_PUBLIC_APP_SECRET` | `ACCLOUD_WORKBENCH_APP_SECRET` | Signing secret. Secret. |
| `ACCLOUD_PUBLIC_VERSION` | `ACCLOUD_WORKBENCH_VERSION` | Observed client version. |
| `ACCLOUD_PUBLIC_DEVICE_TYPE` | — | Observed device type. |
| `ACCLOUD_PUBLIC_IS_CN` | — | Region-routing flag used by the public profile. |
| `ACCLOUD_REGION` | `ACCLOUD_CLIENT_REGION` | Client region header. |
| `ACCLOUD_DEVICE_ID` | `ACCLOUD_CLIENT_DEVICE_ID` | Client device identifier. |
| `ACCLOUD_USER_AGENT` | `ACCLOUD_CLIENT_USER_AGENT` | HTTP user agent. |
| `ACCLOUD_CLIENT_VERSION` | — | Additional client version field used by signing headers. |

## Build options are not runtime variables

`ACCLOUD_ENABLE_QT`, `ACCLOUD_ENABLE_QML_TESTS` and `ACCLOUD_DEBUG` are CMake options. `ACCLOUD_WITH_QT`, `ACCLOUD_WITH_MQTT` and `ACCLOUD_WITH_OPENSSL` are compile definitions generated by the build. They must not be documented as runtime overrides.
